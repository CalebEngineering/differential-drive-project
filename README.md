# differential-drive-project
Differential-drive/Mapping mobile robotics project exploring PID/LQR control, embedded motor control, ROS 2, and LiDAR SLAM

**Status:** In Progress

**Started:** Sept 2026

**Expected completion:** Dec 2026

## Overview
This project focuses on the developement and building of a differential-drive mapping robot using a Raspberry Pi 5 for high-level robotics processing and a STM32 Nucleo-F446RE for low-level motor control.

This Robot will support:
- Closed-Loop PID control for velocity
- Independent Control of 2 DC Motors
- Motor encoder feedback
- Odometry
- SLAM using LiDAR
